# Arkanoid: The Creation of the Big Bang

## Description
**Arkanoid**: The Creation of the Big Bang Edition is a custom version of the classic arcade game *Arkanoid*. In this game, you control a paddle at the bottom of the screen and use it to bounce a ball to break all the bricks. The game features a unique thematic progression with four exciting levels, each having a different background.

## Features

### Gameplay

* Classic Arkanoid with balls and paddle
* Score tracking and lives system
* Lose a life when no balls remain in play
* Multiple balls per level


### 🌍 Levels

Four levels, each with a unique background:

* **Bow and Arrow** - A stage inspired by archery.
* **Beach with Palm Trees** - A tropical seaside setting.
* **Desert Sunset** - A warm-toned desert with silhouettes and birds.
* **Snowman on a Mountain** - A winter landscape featuring a snowman and people.

### ⚙️ Mechanics

* Dynamic number of balls per level
* Increasing difficulty across levels


### ⏸️ Controls

* **Move paddle** – Left / Right keys
* **Pause game** – `P`
* **Resume game** – `Space`

---

## How to Play

* Keep the ball in play using the paddle
* Break all bricks to complete a level
* Avoid losing all balls
* The game ends when you run out of lives

## 🛠️ Installation & Setup

### Prerequisites

Make sure you have installed:

* Java Development Kit (JDK) 11 or later
* Apache Ant (for building and running the project)

---

## ▶️ Run the Game
Open a terminal or command prompt.

### Navigate to the project folder:

```bash
cd path/to/project/Arkanoid
```

### Compile the game:

```bash
ant compile
```

### Run the game:
```bash
ant run
```

### Cleaning the Project
If you need to clean the compiled files, run:

```bash
ant clean
```

This will remove the bin directory and allow you to recompile from scratch.
